 5_4: the purpose of :focus?

It is used when an element is active (like when you click inside an input box).
It helps users see which field they are typing in.


 5-5: input:focus { border: 2px solid blue; }?

It shows a blue border when the user clicks on the input box.
This helps the user know it is ready to type.


 6-2: The rule footer h2 takes precedence because it is more specific.
It targets only the <h2> inside the <footer>, while h1 targets all <h2> elements.
More specific rules always override general ones.
